# Delphi-specific examples

Most of the _Castle Game Engine_ examples should build with Delphi. But the examples in this directory compile _only_ with Delphi.

They show:

- [TCastleControl on FMX and VCL forms](https://castle-engine.io/control_on_form)

- Using [mobile FireMonkey (FMX) services in CGE applications](https://castle-engine.io/delphi_mobile)

- [C++ Builder support](https://castle-engine.io/cpp_builder)
